# Brickfolio Live-Scanner – Umzugsadresse

**Dieses Projekt heißt jetzt [Nupplo Live-Scanner](https://github.com/Melle79/nupplo-livescan).**
Quelltext, Fehlerberichte und alle neuen Fassungen liegen dort.

## Wozu es diesen Ordner noch gibt

Installationen vor Fassung 1.11.0 suchen ihre Erneuerung fest verdrahtet an
dieser Adresse. Nach einer Umbenennung antwortet GitHub hier mit einer
Weiterleitung – und genau die können diese Fassungen nicht lesen. Sie würden
stillschweigend nie wieder eine Erneuerung finden.

Darum liegt hier **eine** Veröffentlichung: `v1.11.1`, mit den Paketen unter
ihren alten Namen. Wer noch auf einer älteren Fassung sitzt, bekommt sie
darüber wie gewohnt eingespielt. Danach zeigt sein Scanner von selbst auf die
neue Adresse und fragt hier nie wieder nach.

Dieser Ordner verschwindet, sobald niemand mehr eine alte Fassung benutzt.
